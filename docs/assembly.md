# การประกอบหุ่น

หุ่นรุ่นสุดท้ายมีของหลักคือ โหลดเซลล์ 20 กก., LED 4 ดวง และบัซเซอร์
แรงจากมือส่งผ่านผิวหน้า ลงแผ่นกดแข็ง แล้วผ่านหนังยางหน่วงไปที่ปลายอิสระของโหลดเซลล์
หนังยางยุบได้ราว 3 ซม. ก่อนที่แผ่นกดจะแตะโหลดเซลล์ ค่าแรงในช่วงนี้จึงเกือบ 0 กก.
มีตัวหยุดแข็งจำกัดระยะกดรวมไว้ที่ประมาณ 6–6.5 ซม.

> สื่อการเรียนรู้ ไม่ใช่เครื่องมือแพทย์

## ของที่ต้องใช้

- ฐานแข็ง เช่น ไม้หนาหรืออะคริลิกหนา
- ผิวหน้าบางสำหรับปิดด้านบน
- แผ่นกดแข็ง เช่น อะคริลิกหนา ตัดให้กว้างพอวางฝ่ามือ
- หนังยางเส้นหนา 4–6 เส้น และโครงสำหรับขึงหนังยาง
- โหลดเซลล์แท่ง 20 กก.
- อะคริลิกแผ่นเล็ก 2 แผ่นสำหรับยึดโหลดเซลล์
- เสาสเปเซอร์และสกรู
- สเปเซอร์เล็ก 1 ตัวสำหรับส่งแรงลงปลายอิสระของโหลดเซลล์
- ตัวหยุดแข็ง เช่น ท่อหรือแท่งอะคริลิก
- สายไฟ หนังยางสำรอง เทป และเคเบิลไทร์
- ผ้าคลุม

## 1. ทำฐานแข็ง

ตัดฐานให้กว้างพอวางฝ่ามือและมั่นคง ไม่โยกเวลาใช้
ยึดขายางหรือแผ่นกันลื่นใต้ฐานถ้าพื้นลื่น
เว้นที่ตรงกลางให้ยึดโหลดเซลล์ และเว้นที่ด้านข้างให้ตั้งตัวหยุดแข็ง

## 2. ยึดโหลดเซลล์ 20 กก.

โหลดเซลล์แท่งต้องทำงานแบบคาน คือยึดปลายหนึ่งกับฐานและให้ปลายอีกด้านงอได้

1. ยึดปลายด้านหนึ่งของโหลดเซลล์กับฐานด้วยอะคริลิกแผ่นและสกรู
   ใช้เสาสเปเซอร์ให้มีช่องว่างระหว่างโหลดเซลล์กับฐาน
2. ปลายด้านที่เหลือต้องลอยและรับแรงจากแผ่นกด
3. วางสเปเซอร์เล็ก ๆ 1 ตัวบนปลายอิสระนี้ เพื่อให้แรงลงที่จุดเดียว
4. อย่าขันสกรูทะลุบริเวณที่โหลดเซลล์ต้องงอ และอย่าให้อะคริลิกกดทับตัววัด
5. ถ้าตัวโหลดเซลล์มีลูกศรบอกทิศทางแรง ให้ติดตั้งตามลูกศร

ตรวจว่าปลายอิสระขยับลงได้เล็กน้อยเมื่อกด และกลับขึ้นเมื่อปล่อย
ถ้าปลายทั้งสองข้างถูกขันแน่น โหลดเซลล์จะไม่งอและอ่านค่าไม่ได้

## 3. ทำหนังยางหน่วง

หนังยางเป็นตัวกลางระหว่างแผ่นกดกับโหลดเซลล์ ทำให้แผ่นกดยุบก่อนแล้วค่อยส่งแรงลงเซลล์

1. ทำโครงเหนือโหลดเซลล์ เช่น เสาสองข้างหรือวงอะคริลิกที่ยึดกับฐาน
   โครงต้องไม่กดทับปลายอิสระของโหลดเซลล์
2. ขึงหนังยาง 4–6 เส้นพาดผ่านโครง ให้อยู่ระดับเดียวกับที่แผ่นกดจะวาง
   ใช้หนังยางชนิดและจำนวนเท่ากันทั้งสองด้าน เพื่อให้แผ่นกดลงตรง ๆ ไม่เอียง
3. วางแผ่นกดบนหนังยาง ให้มีช่องว่างระหว่างสเปเซอร์กับโหลดเซลล์ประมาณ 3 ซม.
   ช่องว่างนี้คือระยะที่แผ่นกดยุบก่อนเริ่มมีแรงลงเซลล์
4. ปิดผิวหน้าแล้ววัดช่องว่างตอนพักอีกที ถ้าแผ่นกดย้วยลงจนช่องว่างเหลือน้อยกว่า 3 ซม.
   ให้ขึงหนังยางให้ตึงขึ้นหรือเพิ่มเส้น
   ถ้ากดช่วง 3 ซม. แรกแล้วรู้สึกแข็งมาก ให้ลดเส้นหรือขึงให้หย่อนลง

หนังยางเสื่อมและหย่อนเมื่อใช้ไปนาน ๆ ให้ตรวจช่องว่าง 3 ซม. เป็นระยะ
ถ้าค่าเริ่มเพี้ยน ให้วัดช่องว่างใหม่แล้วปรับเกณฑ์ตาม [`calibration.md`](calibration.md)

## 4. ติดแผ่นกด

วางแผ่นกดแข็งบนหนังยางโดยให้ด้านล่างแตะหนังยางทั้งสองด้าน
ใต้แผ่นกดต้องมีสเปเซอร์จุดเดียวตรงกับปลายอิสระของโหลดเซลล์
ระยะห่างระหว่างสเปเซอร์กับโหลดเซลล์ตอนพักควรอยู่ราว 3 ซม.

ผิวหน้าบางปิดทับแผ่นกดด้านบน ยึดให้แน่นพอไม่เลื่อน แต่ต้องไม่รั้งแผ่นกด
และต้องบางพอที่จะส่งแรงลงแผ่นกดได้ตรง ๆ

## 5. ตั้งตัวหยุดแข็ง

ตัวหยุดนี้สำคัญมาก เพราะโหลดเซลล์มีพิกัด 20 กก. และมีระยะงอจำกัด
ตัวหยุดต้องรับแรงที่ฐานหรือแท่งแข็ง ไม่ใช่กดลงบนตัวโหลดเซลล์

ตัวหยุดที่สูงกว่าจะทำให้แผ่นกดหยุดเร็วขึ้นและกดได้ตื้นลง
ส่วนตัวหยุดที่เตี้ยลงจะทำให้กดได้ลึกขึ้น ดังนั้นให้ตั้งจากสูงก่อนแล้วค่อย ๆ ลด

1. เริ่มจากตัวหยุดที่ **สูงกว่าเป้า** เพื่อให้แผ่นกดหยุดก่อนถึง 6–6.5 ซม.
2. กดช้า ๆ แล้ววัดระยะที่แผ่นกดเคลื่อนลงด้วยไม้บรรทัด
3. ค่อย ๆ ตัดหรือลดความสูงตัวหยุดทีละน้อย แล้วกดวัดใหม่
4. ทำซ้ำจนแผ่นกดหยุดที่ประมาณ 6–6.5 ซม.
5. ถ้ารู้สึกว่าแรงกดใกล้พิกัดโหลดเซลล์ ให้เพิ่มความสูงตัวหยุดกลับขึ้นมา
   เพื่อให้หยุดเร็วขึ้น

หลังตั้งเสร็จ ให้กดด้วยมือเต็มแรงหนึ่งครั้ง เพื่อดูว่าแผ่นกดชนตัวหยุดจริง
และโหลดเซลล์ไม่ถูกกดเกิน

## 6. เก็บสายและรับแรงดึง

- มัดสาย HX711, สาย LED และสายบัซเซอร์กับฐานด้วยเคเบิลไทร์
- ทำห่วงสายผ่อนแรงก่อนถึงบอร์ด
- อย่าให้สายไปดึงขั้วบัดกรีของ HX711 หรือโหลดเซลล์
- ติดป้ายสายแต่ละเส้นก่อนปิดฝา
- เก็บสายให้พ้นบริเวณที่แผ่นกดและหนังยางเคลื่อนที่

## 7. ปิดด้วยผิวหน้า

ปิดด้านบนด้วยผิวหน้าบางหรือผ้าที่ถอดซักได้
ผ้าต้องไม่รั้งแผ่นกดและไม่ไปกดหนังยางตอนที่ยังไม่มีมือวาง
ตรวจว่าผิวหน้าไม่ทำให้แผ่นกดเอียง

## ตรวจก่อนใช้

- กดเบา ๆ แล้วดูว่าแผ่นกดกลับขึ้นเต็มที่
- กดเต็มแรงแล้วดูว่าแผ่นกดชนตัวหยุด ไม่กดโหลดเซลล์เกิน
- วัดระยะกดสูงสุดด้วยไม้บรรทัด ได้ประมาณ 6–6.5 ซม.
- กดช่วงแรกประมาณ 3 ซม. ค่า กก. ยังใกล้ศูนย์ แล้วจึงค่อยขึ้น
- เอามือออก แล้วค่าแรงกลับไปใกล้ศูนย์
- กดแล้ว LED กำลังกดติด ปล่อยแล้วดับ
- LED ลึกพอดี, ตื้นไป และลึกไป ตรงกับค่าที่อ่านได้
- ตรวจสายไฟไม่ตึงและไม่สีกับขอบอะคริลิก
- ตรวจหนังยางไม่ขาดและไม่หย่อนจนช่องว่าง 3 ซม. หายไป

## ความปลอดภัย

- ใช้อุปกรณ์ไฟฟ้าแรงต่ำเท่านั้น ไม่ต่อไฟบ้านเข้ากับหุ่น
- ระวังขอบอะคริลิกบาดมือ
- อย่ายืนหรือทิ้งน้ำหนักตัวลงบนหุ่น ใช้มือกดตามที่ฝึกเท่านั้น
- อย่าให้เด็กเล็กใช้โดยไม่มีผู้ใหญ่ดูแล
- ถ้ามีกลิ่นไหม้ สายร้อน หรือค่าแปลก ให้ถอดไฟทันที
- ตัวหยุดแข็งต้องอยู่ตลอดเวลา อย่าถอดออกเพื่อให้กดได้ลึกขึ้น

## หมายเหตุ build เก่า

build เก่าเคยใช้ VL53L0X วัดระยะกดและสวิตช์ฟอยล์บอกตำแหน่งมือ
โค้ดทั้งสองยังอยู่ในโปรเจกต์หลัง `USE_VL53L0X` และ `CPR_HAS_FOIL`
แต่ build ESP32 รุ่นสุดท้ายปิดทั้งคู่ ส่วน Nano ยังอ่านสวิตช์ฟอยล์เหมือนเดิม
