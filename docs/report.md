# ส่วนสำหรับรายงานโรงเรียน

ข้อความในหน้านี้เขียนให้คัดลอกไปใช้ในรายงานได้ ปรับสำนวนให้เข้ากับรูปแบบของโรงเรียน
ตัวเลขและเกณฑ์ทั้งหมดมาจากโค้ดจริงและ `docs/DESIGN.md`

> สื่อการเรียนรู้ ไม่ใช่เครื่องมือแพทย์

## 1. หลักการทำงาน

หุ่นฝึก CPR เด็กวัดการกดหน้าอกด้วยเซนเซอร์สามชนิด

- **โหลดเซลล์ 20 กก.** อยู่ใต้แผ่นกด วัดแรงที่มือกดลงไป ผ่านตัวขยายสัญญาณ HX711
- **VL53L0X** วัดระยะที่แผ่นกดเคลื่อนลง โดยติดไว้ที่ฐานและมองขึ้นไปที่แผ่นกด
  เป็นอุปกรณ์เสริม ใช้กับ ESP32
- **สวิตช์ฟอยล์** อยู่ใต้ฝ่ามือ ใช้บอกว่ามือวางอยู่กลางหน้าอกหรือไม่

เฟิร์มแวร์อ่านค่าจากเซนเซอร์ กรองสัญญาณ ตรวจจับการกดหนึ่งครั้ง
แล้วประเมินสี่อย่าง คือ ความลึก อัตราการกด การคืนตัว และตำแหน่งมือ
ผลแสดงด้วย LED 4 ดวง บัซเซอร์ และหน้าเว็บ
บอร์ด ESP32 เปิด Wi-Fi ให้เข้าแดชบอร์ดได้เอง ส่วน Nano ส่งข้อมูลผ่าน Serial
ให้หน้าเว็บอ่านผ่าน Web Serial

## 2. วิธีวัดแต่ละอย่าง

### ความลึก

ถ้ามี VL53L0X เฟิร์มแวร์จะอ่านระยะจากเซนเซอร์ถึงแผ่นกด
แล้วหักลบด้วยระยะพักที่อ่านตอนบูตหรือตอนสั่ง `tare`
ค่าที่ได้เป็นมิลลิเมตรและไม่ต่ำกว่าศูนย์

ถ้าไม่มี ToF แต่มีแผนที่แรงเป็นความลึก จะแปลงค่า กก. เป็น มม.
ด้วยแผนที่ที่ปรับเทียบไว้ ถ้าไม่มีทั้งสองอย่าง จะใช้แรงเป็นตัวตัดสิน
โดยเทียบกับช่วง กก. ที่ตั้งไว้

### อัตราการกด

เฟิร์มแวร์จำเวลาเริ่มกดครั้งล่าสุดไว้สูงสุด 5 ครั้ง
แล้วคำนวณ

```
bpm = 60000 * (จำนวนครั้ง - 1) / (เวลาครั้งล่าสุด - เวลาครั้งแรก)
```

ถ้ามีการกดน้อยกว่า 2 ครั้ง จะยังไม่รู้อัตรา (แสดง 0)
ค่าถูกปัดเป็นจำนวนเต็มและจำกัดไว้ที่ 0–250 ครั้ง/นาที
หลังหยุดพัก ตัวประมาณอัตราจะเริ่มนับใหม่ และการกดครั้งแรกหลังพักจะไม่มีระดับอัตรา

### การคืนตัว

เมื่อปล่อยมือ ค่าสัญญาณต้องลดลงถึงเส้นคืนตัว เช่น 5 มม. หรือ 0.5 กก.
จึงนับว่าคืนตัวสุด ถ้ามีการกดครั้งใหม่ก่อนที่ค่าจะลดถึงเส้นนี้
ครั้งเดิมจะถูกนับว่าคืนตัวไม่สุด ถ้าไม่มีอะไรเกิดขึ้นภายในเวลากำหนด
ระบบจะตัดสินจากค่าต่ำสุดที่วัดได้หลังปล่อยมือ

### ตำแหน่งมือ

สวิตช์ฟอยล์จะปิดเมื่อมือกดถูกบริเวณกลางหน้าอก
เฟิร์มแวร์นับจำนวนตัวอย่างที่สวิตช์ปิดเทียบกับจำนวนตัวอย่างทั้งหมดในการกด
ถ้าปิดอย่างน้อยครึ่งหนึ่ง จะถือว่าตำแหน่งมือถูกต้อง

### การหยุดกดและ CCF

ถ้าไม่มีการกดนานกว่า 2 วินาทีระหว่างรอบ ระบบจะเริ่มนับช่วงหยุด
ช่วงหยุดที่ยาวกว่า 10 วินาทีถือว่านานเกินไป
CCF คือสัดส่วนเวลาที่กดต่อเนื่องเทียบกับเวลาทั้งรอบ

```
CCF % = 100 * (1 - เวลาหยุดรวม / ระยะเวลารอบ)
```

รอบจะจบเมื่อกด **จบรอบ** เมื่อครบ 2 นาทีในโหมด 2 นาที
หรือเมื่อไม่มีการกดต่อเนื่อง 30 วินาที

## 3. อัลกอริทึม

ข้อมูลหนึ่งตัวอย่างประกอบด้วยเวลา แรงเป็น กก. ความลึกเป็น มม. และสถานะมือ
เฟิร์มแวร์เลือกแหล่งข้อมูลตอนที่ยังไม่มีการกด และไม่สลับแหล่งกลางการกด
เพื่อไม่ให้ค่ากระโดด

### ตัวกรอง

1. รับค่าดิบ 3 ค่าล่าสุด หาค่ามัธยฐาน เพื่อตัดค่ากระโดด
2. ป้อนค่ามัธยฐานเข้าตัวกรอง EMA ด้วยค่า alpha 0.5
3. ค่าที่ไม่ใช่ตัวเลข (NAN) จะถูกข้าม และคืนค่าเดิม

### เครื่องตรวจการกด

เครื่องตรวจมีสี่สถานะ ใช้ hysteresis เพื่อไม่ให้นับครั้งเดียวซ้ำ

```
Idle
  |  ค่า >= contact
  v
Pressing  ── ค่าลดลงต่ำกว่า max * (1 - 0.15) ──>  Peak
                                                      |
                                                      | ตัวอย่างถัดไป
                                                      v
                                                  Releasing
                                                   |       |
                         ค่า <= release ───────────+       +── lo > release
                                  |                          และค่า >= lo + restartDelta
                                  v                                |
                          Idle (รอผลการคืนตัว)                     v
                                  |                        จบครั้งเดิม (recoil = false)
                    ค่า <= recoil | ครบ handsOffMs          เริ่ม Pressing ใหม่
                                  v
                            ส่งผลการกดหนึ่งครั้ง
```

- **Pressing** จำค่าสูงสุดและเวลาที่ยอดเกิด
- **Peak** อยู่นานหนึ่งตัวอย่าง แล้วไปที่ Releasing
- **Releasing** จำค่าต่ำสุดระหว่างปล่อยเพื่อรอการคืนตัว
- ถ้าผู้ใช้ยังเอนมือค้างและเริ่มกดใหม่ ระบบจะจบครั้งเดิมโดยนับว่าคืนตัวไม่สุด
  แล้วเริ่มครั้งใหม่ทันที
- การนับมือใช้จำนวนตัวอย่างที่สวิตช์ปิดอย่างน้อยครึ่งหนึ่งของการกด

หลังได้ผลการกด ระบบจะ

1. แบ่งระดับความลึกจากค่ายอด เป็นตื้นไป พอดี หรือลึกไป
2. แบ่งระดับอัตราจาก bpm เป็นช้าไป พอดี หรือเร็วไป
3. รวมผลเป็น "ถูกทั้งหมด" เมื่อความลึกพอดี อัตราพอดีหรือยังไม่รู้
   การคืนตัวสุด และมือถูกตำแหน่ง
4. สะสมสถิติลงในหน้าสรุป

### สถิติและคะแนน

หน้าสรุปรวมจำนวนครั้ง แยกตามระดับความลึก ระดับอัตรา การคืนตัว ตำแหน่งมือ
และครั้งที่ถูกทั้งหมด พร้อมเวลาเริ่ม เวลาจบ เวลาหยุดรวม เวลาหยุดนานสุด
และจำนวนรอบ 30:2

คะแนน 0–100 คำนวณจาก

```
0.30 * ความลึกถูก %
+ 0.25 * จังหวะถูก %
+ 0.20 * คืนตัวสุด %
+ 0.10 * มือถูกตำแหน่ง %
+ 0.15 * min(100, CCF % * 100 / 60)
```

น้ำหนักเหล่านี้เป็นค่าของทีม ไม่ใช่มาตรฐานทางการแพทย์

### โหมดฝึก

- **อิสระ** นับทุกครั้งจนกดจบหรือหยุดนาน 30 วินาที
- **30:2** นับ 30 ครั้ง แล้วรอช่วงหายใจ 2 ครั้ง รอบจะปิดเมื่อเริ่มพักครั้งถัดไป
- **2 นาที** จบอัตโนมัติเมื่อครบ 120 วินาทีหลังการกดครั้งแรก

## 6. ข้อจำกัด

- โหลดเซลล์วัด **แรง** ไม่ได้วัดความลึกโดยตรง ความลึกจึงต้องมาจาก ToF
  หรือจากแผนที่แรงเป็นความลึกที่ปรับเทียบกับหุ่นชุดนี้
- ค่าปรับเทียบผูกกับฟองน้ำ โครงยึด และจุดรับแรงของหุ่นชุดนี้
  ถ้าเปลี่ยนฟองน้ำหรือประกอบใหม่ ต้องปรับเทียบใหม่
- ฟองน้ำเปลี่ยนสภาพตามเวลา ความชื้น และอุณหภูมิ ค่าที่เคยตั้งไว้อาจเปลี่ยน
- VL53L0X เป็นอุปกรณ์เสริม และ Nano build ปกติไม่มีความจำพอสำหรับ ToF
  จึงต้องใช้การตั้งช่วงด้วยแรงแทน
- สวิตช์ฟอยล์บอกเพียงว่ามืออยู่ในบริเวณที่กำหนด ไม่ได้ตรวจท่ามือหรือตำแหน่งกระดูกทั้งหมด
- โครงงานนี้ทำโหมด 30:2 สำหรับคนกู้ชีพคนเดียว ยังไม่มีโหมด 15:2 สำหรับเด็กสองคน
- ไม่ได้วัดการหายใจจริง ระบบเพียงนับช่วงพักระหว่างรอบ
- คะแนนเป็นค่าของทีม ไม่ใช่เกรดมาตรฐาน และยังไม่ได้ทดสอบกับผู้เรียนจำนวนมาก
- ตัวเลขผลทดสอบมาจากซิมูเลเตอร์ ไม่ใช่การทดลองกับคนจริง
- หุ่นนี้เป็นสื่อการเรียนรู้ ไม่ใช่เครื่องมือแพทย์ และใช้รับรองความสามารถไม่ได้

หมายเหตุ

- จำนวนครั้งที่มีอัตราน้อยกว่า n เล็กน้อย เพราะการกดครั้งแรกของรอบยังไม่มีอัตรา
  และระบบนับเฉพาะครั้งที่มีอัตราแล้ว
- `good`, `shallow`, `deep` จำแนกระดับความลึกได้ตรงตามที่สร้างสัญญาณ
- `fast` และ `slow` จำแนกระดับอัตราได้ตรง โดย bpm เฉลี่ยเป็น 135 และ 85
- `norecoil` ได้คืนตัวดี 0 ครั้ง และถูกทั้งหมด 0 ครั้ง
- `wronghand` ได้มือดี 21 จาก 73 ครั้ง ตามสัดส่วนที่ตัวสร้างกำหนด
- `noisy` ยังนับจำนวนครั้งได้ใกล้เคียงและจำแนกได้ถูกต้อง
- `cycle` ได้ 4 รอบ, CCF 77% เพราะมีช่วงพักหายใจ 5 วินาที และไม่มีการหยุดนานเกิน 10 วินาที
- `test2min` จบที่ 120 วินาทีพอดี
- `kgonly_good` ใช้แรงล้วนและได้ผลเหมือนโหมดความลึก
- `lowsps_good` แสดงปัญหาของ HX711 ที่ 10 SPS: ยอดกดถูกพลาด
  ทำให้การกดที่ดีถูกจัดเป็นตื้นไป และการคืนตัวถูกประเมินผิด
