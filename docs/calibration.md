# การปรับเทียบ

หุ่นต้องรู้ว่าน้ำหนักเท่าไรคือความลึกเท่าไร และต้องรู้ว่าตอนไม่มีมือกด
ค่าแรงเป็นศูนย์ การปรับเทียบแบ่งเป็นตั้งศูนย์ ตั้งน้ำหนัก และตั้งช่วงความลึก
ทำได้ทั้งจากหน้าเว็บและจากคำสั่ง Serial

> สื่อการเรียนรู้ ไม่ใช่เครื่องมือแพทย์

## ตอนบูตเครื่องทำอะไร

- โหลดค่าปรับเทียบที่บันทึกไว้จากหน่วยความจำ
- ถ้าไม่มีค่าที่ใช้ได้ จะใช้ค่าเริ่มต้น คือมาตราส่วน `-10000.0` และช่วง กก. 6/12
- รอ HX711 ประมาณ 800 มิลลิวินาที แล้ว tare 10 ค่า
- ถ้ามี VL53L0X จะอ่านระยะพัก 10 ค่า
- ถ้าไม่พบเซนเซอร์ จะเขียนบรรทัด `# HX711 not found` หรือ
  `# VL53L0X not found` แล้วทำงานต่อเท่าที่มี

เพราะมีการ tare ตอนบูต ทุกครั้งที่เปิดเครื่องควรวางหุ่นบนพื้นเรียบ
และไม่มีมือหรือของวางบนแผ่นกด

## ปรับเทียบจากหน้าเว็บ

เปิด **ตั้งค่า** แล้วกด **เปิดตัวช่วย** ในหัวข้อปรับเทียบ
ตัวช่วยมี 4 ขั้น

1. **ตั้งศูนย์**: ยกมือออกจากหุ่น กด **ตั้งศูนย์** (ส่งคำสั่ง `tare`)
2. **น้ำหนัก**: วางของที่รู้น้ำหนักจริงบนแผ่นกด กรอกน้ำหนักเป็น กก.
   แล้วกด **บันทึกน้ำหนัก** (ส่ง `cal weight <kg>`)
   หน้าเว็บรับค่า 0.2–20 กก. อุปกรณ์จะเฉลี่ยค่าดิบ 20 ครั้ง ภายในเวลาไม่เกิน 3 วินาที
3. **ช่วงกด**: ถ้ามี ToF จะเริ่มบันทึกอัตโนมัติ ให้กดช้า ๆ 5–10 ครั้ง
   ให้ลึกสุดประมาณ 6 ซม. แล้วกด **เสร็จสิ้น** (ส่ง `cal finish`)
   ถ้าไม่มี ToF ให้ทำตามหัวข้อ "ไม่มี VL53L0X" ด้านล่าง
4. **บันทึก**: กด **บันทึก** (ส่ง `cal save`) เพื่อเขียนลงหน่วยความจำ

หลังบันทึก หน้าเว็บจะได้รับ `cfg` ใหม่ และใช้ค่าปรับเทียบนี้ทันที

## มี VL53L0X: สร้างแผนที่แรงเป็นความลึก

คำสั่งที่ใช้

```
tare
cal weight 2.0
cal start
... กดช้า ๆ หลายครั้ง ให้ลึกสุดประมาณ 6 ซม. ...
cal finish
cal save
```

- `cal start` เริ่มเก็บคู่ (kg, mm) จากทุกตัวอย่างที่อ่านได้ทั้งสองค่า
- เก็บได้สูงสุด 48 คู่บน ESP32 (Nano ตั้งไว้ 16 คู่ แต่ build ปกติไม่มี ToF)
- `cal finish` จะจัดกลุ่มค่าเป็นจุดแผนที่ได้สูงสุด 8 จุด
  และบังคับให้ความลึกเพิ่มขึ้นตามแรง
- ถ้าเก็บได้น้อยกว่า 2 จุด จะตอบ `need 2 points`
- หลังสร้างแผนที่ เฟิร์มแวร์จะใช้แหล่ง **แมปความลึก** เมื่อไม่ใช้ ToF โดยตรง

กดช้า ๆ และกดให้สุดใกล้ ๆ กันหลายครั้ง อย่ากดแรงเกินตัวหยุด
ถ้าเปลี่ยนฟองน้ำ เปลี่ยนความสูงชั้น หรือเปลี่ยนจุดยึดโหลดเซลล์ ต้องทำใหม่

## ไม่มี VL53L0X: ตั้งช่วงด้วยแรง

วิธีนี้ใช้ได้กับ Nano และ ESP32 ที่ไม่ได้ติด ToF
ต้องมีไม้บรรทัดวัดระยะกดจริง

1. ตั้งศูนย์ด้วย `tare`
2. ตั้งน้ำหนักด้วย `cal weight <kg>` ถ้ามีของที่รู้น้ำหนัก
3. กดให้ได้ 5 ซม. ตามไม้บรรทัด ปล่อยมือ แล้วอ่านค่ายอดล่าสุด

   ```
   cal peak
   ```

   อุปกรณ์จะตอบค่าเป็น กก. เช่น `{"ty":"ack","cmd":"cal peak","ok":1,"msg":"6.4"}`

4. ทำซ้ำที่ 6 ซม. แล้วอ่าน `cal peak` อีกครั้ง
5. ตั้งช่วงด้วยค่าทั้งสอง

   ```
   cal bands 6.4 9.2
   ```

   ค่าแรกคือจุดเริ่ม "พอดี" ค่าที่สองคือจุดเริ่ม "ลึกเกินไป"
   ค่าที่สองต้องมากกว่าค่าแรก

6. `cal save`

ในหน้าเว็บ ขั้นที่ 3 จะมีปุ่ม **บันทึกจุด 5 ซม.** และ **บันทึกจุด 6 ซม.**
ให้กดปุ่มหลังการกดแต่ละครั้ง แล้วกด **ใช้ช่วงนี้** (ส่ง `cal bands`)

`cal peak` ใช้ได้เมื่อการกดครั้งล่าสุดมาจากโหลดเซลล์โดยตรง
ถ้าเปิด ToF อยู่ ค่ายอดจะเป็นมิลลิเมตรและ `cal peak` อาจตอบ `no peak`

## คำสั่งที่เกี่ยวกับการปรับเทียบ

| คำสั่ง | ทำงาน |
|---|---|
| `tare` | ตั้งศูนย์โหลดเซลล์ และอ่านระยะพัก ToF ใหม่ |
| `cal weight <kg>` | ตั้งมาตราส่วนจากน้ำหนักที่รู้ค่า |
| `cal start` | เริ่มเก็บคู่แรงกับความลึก ต้องมี ToF |
| `cal finish` | สร้างแผนที่จากคู่ที่เก็บไว้ ต้องมี ToF |
| `cal cancel` | ทิ้งคู่ที่เก็บไว้ |
| `cal peak` | ตอบค่ายอดกดครั้งล่าสุดเป็น กก. |
| `cal bands <goodKg> <deepKg>` | ตั้งช่วงความลึกด้วยแรง |
| `cal save` | เขียนค่าลงหน่วยความจำ |
| `cal reset` | คืนค่าปรับเทียบเริ่มต้น |
| `config` | ขอ `cfg` ปัจจุบัน |

ทุกคำสั่งมี `ack` ตอบกลับ ตัวอย่างความล้มเหลวที่พบบ่อยคือ `no tof`,
`no hx711`, `bad weight`, `bad bands` และ `need 2 points`

## เก็บไว้ที่ไหน

| บอร์ด | ที่เก็บ | รายละเอียด |
|---|---|---|
| ESP32 | NVS ผ่าน `Preferences` | namespace `cpr`, key `cal` เป็นก้อนข้อมูลไม่เกิน 96 ไบต์ |
| ESP32 | NVS | key `wifipass` เก็บรหัส Wi-Fi แยกจากค่าโหลดเซลล์ |
| Nano | EEPROM | เริ่มที่ address 0 ใช้รูปแบบเดียวกับ ESP32 |

ก้อนข้อมูลเก็บมาตราส่วน แผนที่แรงเป็นความลึก ช่วง กก. และโปรไฟล์
การเปลี่ยนโปรไฟล์จากแถบล่างหรือหน้าตั้งค่าจะมีผลทันที
แต่จะอยู่ต่อหลังรีบูตก็ต่อเมื่อสั่ง `cal save` แล้วเท่านั้น

## คืนค่าเริ่มต้น

```
cal reset
cal save
```

`cal reset` คืนค่าในหน่วยความจำชั่วคราวและส่ง `cfg` ใหม่
ถ้าต้องการให้ค่าเริ่มต้นอยู่หลังรีบูต ต้องตามด้วย `cal save`
หลังคืนค่า ให้ตั้งศูนย์และตั้งน้ำหนักใหม่ก่อนใช้งานจริง

## ตรวจว่าปรับเทียบสำเร็จ

- วางของที่รู้น้ำหนัก เช่น ขวดน้ำ 2.0 กก. แล้วดูค่า กก. ในหน้าเว็บ
  ควรใกล้เคียงค่าจริง
- ส่ง `config` แล้วดู `cfg`
  - `prof` เป็น 1 เมื่อใช้โปรไฟล์เด็ก (ค่าเริ่มต้น) และ 0 เมื่อใช้ผู้ใหญ่
  - `unit` เป็น `mm` เมื่อใช้ ToF หรือแผนที่ และเป็น `kg` เมื่อใช้แรงล้วน
  - `gmin`, `dmin` คือช่วงความลึกเป็นมิลลิเมตร
  - `gkg`, `dkg` คือช่วงความลึกเป็นกิโลกรัม
  - `map` คือจำนวนจุดของแผนที่ ถ้ามากกว่า 1 แปลว่ามีแผนที่แล้ว
- ที่แถบล่างของหน้าเว็บ แหล่งข้อมูลจะแสดง `ToF`, `แมปความลึก` หรือ `โหลดเซลล์`
- กดหนึ่งครั้งแล้วดูหน้าสรุปว่าความลึกอยู่ในช่วงที่ตั้งไว้
- ถ้าค่าเพี้ยน ให้ `tare` ใหม่ แล้วลองชั่งของที่รู้น้ำหนักอีกครั้ง

## ข้อควรระวัง

- ค่าปรับเทียบผูกกับฟองน้ำและโครงหุ่นชุดนี้ ไม่สามารถใช้ข้ามหุ่นได้
- ฟองน้ำเปลี่ยนสภาพตามเวลา ความชื้น และอุณหภูมิ ควรตั้งศูนย์ก่อนฝึกทุกครั้ง
- อย่าตั้งตัวหยุดให้ลึกขึ้นเพื่อให้ได้เลข 6 ซม. ถ้าโหลดเซลล์เริ่มรับแรงมาก
- ถ้าใช้แผนที่ความลึก ควรมีจุดข้อมูลทั้งช่วงตื้นและช่วงลึก ไม่ควรเก็บแต่จุดเดียว
