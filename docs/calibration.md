# การปรับเทียบ

หุ่นต้องรู้ว่าน้ำหนักเท่าไรคือความลึกเท่าไร และต้องรู้ว่าตอนไม่มีมือกด
ค่าแรงเป็นศูนย์ การปรับเทียบแบ่งเป็นตั้งศูนย์ ตั้งน้ำหนัก และตั้งเกณฑ์ความลึก
ทำได้ทั้งจากหน้าเว็บและจากคำสั่ง Serial

> สื่อการเรียนรู้ ไม่ใช่เครื่องมือแพทย์

## ตอนบูตเครื่องทำอะไร

- โหลดค่าปรับเทียบที่บันทึกไว้จากหน่วยความจำ
- ถ้าไม่มีค่าที่ใช้ได้ จะใช้ค่าเริ่มต้น คือมาตราส่วน `-10000.0`
  และเกณฑ์ ผ่าน 6 กก. / ลึกไป 12 กก. / เกินแรง 18 กก.
  เริ่มกด 0.5 กก. / คืนตัว 0.2 กก. / ความไว 1.0
- รอ HX711 พร้อมไม่เกิน 3 วินาที ทิ้งค่าแรก 4 ครั้ง แล้ว tare
  โดยอ่านสองชุด ๆ ละ 8 ค่า และตรวจว่าใกล้กันพอ
- ถ้าไม่พบ HX711 จะเขียนบรรทัด `# HX711 not found` แล้วลองใหม่เองทุกวินาที

เพราะมีการ tare ตอนบูต ทุกครั้งที่เปิดเครื่องควรวางหุ่นบนพื้นเรียบ
และไม่มีมือหรือของวางบนแผ่นกด

## ปรับเทียบจากหน้าเว็บ

เปิดเมนู **ตั้งค่า** แล้วแตะแถว **ปรับเทียบ**
ตัวช่วยมี 4 ขั้น

1. **ศูนย์**: **ยกมือออกจากหุ่น** แล้วกด **ตั้งศูนย์** (ส่งคำสั่ง `tare`)
2. **น้ำหนัก**: **วางของที่รู้น้ำหนัก** กรอกน้ำหนักเป็น กก. แล้วกด **บันทึก** (ส่ง `cal weight <kg>`)
   หน้าเว็บรับค่า 0.2–20 กก. อุปกรณ์จะเฉลี่ยค่าดิบ 20 ครั้ง ภายในเวลาไม่เกิน 3 วินาที
3. **ช่วงกด**: กดให้ลึก 5 ซม. ตามไม้บรรทัด แล้วกด **เก็บค่า**
   จากนั้นกดให้ลึก 6 ซม. แล้วกด **เก็บค่า** อีกครั้ง
   ระบบจะส่ง `cal bands` ให้เอง และเขียนค่า ผ่าน กับ ลึกไป ให้
4. **บันทึก**: ตรวจค่าที่หัวข้อ **บันทึกลงหุ่น** แล้วกด **บันทึก** (ส่ง `cal save`) เพื่อเขียนลงหน่วยความจำ

หลังบันทึก หน้าเว็บจะขึ้น **เรียบร้อย** และใช้ค่าปรับเทียบนี้ทันที

## ปรับเกณฑ์สำหรับหุ่นที่มีหนังยางหน่วง

หุ่นรุ่นสุดท้ายมีหนังยางกั้นระหว่างแผ่นกดกับโหลดเซลล์
แผ่นกดยุบได้ราว 3 ซม. ก่อนแตะโหลดเซลล์ ช่วงนั้นค่าแรงจะเกือบ 0 กก.
และจะเริ่มขึ้นหลังจากนั้น จึงต้องตั้งเกณฑ์จากน้ำหนักที่อ่านได้หลังแผ่นกดแตะเซลล์แล้ว

1. ตั้งศูนย์ด้วย `tare` ตอนไม่มีมือวางบนหุ่น
2. ตั้งน้ำหนักด้วยของที่รู้ค่าด้วย `cal weight <kg>`
3. เปิด **ตั้งค่า > เกณฑ์**
4. กดแบบที่คิดว่าดี วัดด้วยไม้บรรทัดให้ได้ราว 5 ซม.
   ดูค่า **ล่าสุด X.X** แล้วตั้ง **ผ่าน** ให้ต่ำกว่าค่ายอดนั้นเล็กน้อย
5. กดให้ได้ราว 6 ซม. ดูค่า **ล่าสุด X.X** แล้วตั้ง **ลึกไป** จากค่ายอดนั้น
6. ตั้ง **เริ่มกด** ให้ต่ำ ประมาณ 0.3–0.8 กก.
   เพราะช่วง 3 ซม. แรกค่าเกือบ 0 และไม่ควรทำให้เริ่มนับผิด
7. ตั้ง **คืนตัว** ให้ต่ำ ประมาณ 0.1–0.3 กก.
   ค่านี้คือจุดที่แผ่นกดยกออกจากโหลดเซลล์
8. ถ้ากดเร็วประมาณ 120 ครั้ง/นาที แล้วหน้าเว็บขึ้น **ยังค้าง**
   ให้เพิ่ม **คืนตัว** ขึ้นเล็กน้อย หรือตั้ง **ความไว** เป็น **ไว**

ขั้น **ช่วงกด** ของตัวช่วยปรับเทียบยังใช้ได้เหมือนเดิม
เมื่อเก็บค่า 5 ซม. และ 6 ซม. ครบ มันจะส่ง `cal bands ...`
และเขียนค่า ผ่าน กับ ลึกไป ให้เอง

หลังปรับเกณฑ์แล้ว ให้กดทดสอบหลาย ๆ ครั้งทั้งช้าและเร็ว
ถ้าค่า ผ่าน เริ่มหลุดบ่อย ให้ลดลงอีก 0.5 กก. แล้วลองใหม่

## build เก่าที่มี ToF: สร้างแผนที่แรงเป็นความลึก

build เก่าที่เปิด `USE_VL53L0X` ใช้คำสั่งชุดนี้ได้

```
tare
cal weight 2.0
cal start
... กดช้า ๆ หลายครั้ง ให้ลึกสุดประมาณ 6 ซม. ...
cal finish
cal save
```

- `cal start` เริ่มเก็บคู่ (kg, mm) จากทุกตัวอย่างที่อ่านได้ทั้งสองค่า
- เก็บได้สูงสุด 48 คู่บน ESP32 (Nano ตั้งไว้ 16 คู่ แต่ build ปกติไม่มี ToF)
- `cal finish` จะจัดกลุ่มค่าเป็นจุดแผนที่ได้สูงสุด 8 จุด
  และบังคับให้ความลึกเพิ่มขึ้นตามแรง
- ถ้าเก็บได้น้อยกว่า 2 จุด จะตอบ `need 2 points`
- หลังสร้างแผนที่ เฟิร์มแวร์จะใช้แหล่ง **แมปความลึก** เมื่อไม่ใช้ ToF โดยตรง

กดช้า ๆ และกดให้สุดใกล้ ๆ กันหลายครั้ง อย่ากดแรงเกินตัวหยุด
ถ้าเปลี่ยนหนังยาง เปลี่ยนความสูงชั้น หรือเปลี่ยนจุดยึดโหลดเซลล์ ต้องทำใหม่

## ไม่มี ToF: ตั้งเกณฑ์ด้วยแรง

วิธีนี้ใช้กับ ESP32 รุ่นสุดท้ายและ Nano
ต้องมีไม้บรรทัดวัดระยะกดจริง

1. ตั้งศูนย์ด้วย `tare`
2. ตั้งน้ำหนักด้วย `cal weight <kg>` ถ้ามีของที่รู้น้ำหนัก
3. กดให้ได้ 5 ซม. ตามไม้บรรทัด ปล่อยมือ แล้วอ่านค่ายอดล่าสุด

   ```
   cal peak
   ```

   อุปกรณ์จะตอบค่าเป็น กก. เช่น `{"ty":"ack","cmd":"cal peak","ok":1,"msg":"6.4"}`

4. ทำซ้ำที่ 6 ซม. แล้วอ่าน `cal peak` อีกครั้ง
5. ตั้งช่วงด้วยค่าทั้งสอง

   ```
   cal bands 6.4 9.2
   ```

   ค่าแรกคือจุดเริ่ม "ผ่าน" ค่าที่สองคือจุดเริ่ม "ลึกไป"
   ค่าที่สองต้องมากกว่าค่าแรก

6. `cal save`

ในหน้าเว็บ ขั้นที่ 3 จะมีช่อง 5 ซม. และ 6 ซม. ให้กด **เก็บค่า** หลังการกดแต่ละครั้ง
เมื่อเก็บครบทั้งสองจุด ระบบจะส่ง `cal bands` ให้เอง

`cal peak` ใช้ได้เมื่อการกดครั้งล่าสุดมาจากโหลดเซลล์โดยตรง
ถ้า build เก่าเปิด ToF อยู่ ค่ายอดจะเป็นมิลลิเมตรและ `cal peak` อาจตอบ `no peak`

## คำสั่งที่เกี่ยวกับการปรับเทียบ

| คำสั่ง | ทำงาน |
|---|---|
| `tare` | ตั้งศูนย์โหลดเซลล์ (อ่านระยะพัก ToF ด้วยถ้า build เก่าเปิดไว้) |
| `cal weight <kg>` | ตั้งมาตราส่วนจากน้ำหนักที่รู้ค่า |
| `cal start` | เริ่มเก็บคู่แรงกับความลึก ต้องมี ToF |
| `cal finish` | สร้างแผนที่จากคู่ที่เก็บไว้ ต้องมี ToF |
| `cal cancel` | ทิ้งคู่ที่เก็บไว้ |
| `cal peak` | ตอบค่ายอดกดครั้งล่าสุดเป็น กก. |
| `cal bands <goodKg> <deepKg>` | ตั้งช่วงความลึกด้วยแรง |
| `cal save` | เขียนค่าลงหน่วยความจำ |
| `cal reset` | คืนค่าปรับเทียบเริ่มต้น |
| `config` | ขอ `cfg` ปัจจุบัน |

ทุกคำสั่งมี `ack` ตอบกลับ ตัวอย่างความล้มเหลวที่พบบ่อยคือ `no tof`,
`no hx711`, `bad weight`, `bad bands` และ `need 2 points`

## ตั้งเกณฑ์จาก Serial

ผู้ที่ใช้ Serial ตั้งเกณฑ์ได้โดยไม่ต้องเปิดหน้าเว็บ
ค่าเป็นกิโลกรัม และเรียงตามนี้

| คำสั่ง | ทำงาน |
|---|---|
| `set th <good> <deep> <over> <contact> <recoil> <filt>` | ตั้งทั้งชุด เช่น `set th 6.0 12.0 18.0 0.5 0.2 1.0` |
| `set good 6.0` | ตั้งค่า ผ่าน |
| `set deep 12.0` | ตั้งค่า ลึกไป |
| `set over 18.0` | ตั้งค่า เกินแรง |
| `set contact 0.5` | ตั้งค่า เริ่มกด |
| `set recoil 0.2` | ตั้งค่า คืนตัว |
| `set filter 1.0` | ตั้งค่าความไว (0.2–1.0) |
| `set reset` | คืนค่าเริ่มต้นทั้งหมด |

อุปกรณ์จะตอบ `ack` แล้วส่ง `cfg` ใหม่มาให้
ค่าที่ตั้งจะถูกเก็บลงหน่วยความจำทันที

## เก็บไว้ที่ไหน

| บอร์ด | ที่เก็บ | รายละเอียด |
|---|---|---|
| ESP32 | NVS ผ่าน `Preferences` | namespace `cpr`, key `cal` เป็นก้อนข้อมูลไม่เกิน 96 ไบต์ |
| ESP32 | NVS | key `th` เก็บเกณฑ์ที่ผู้ใช้ตั้ง และ key `wifipass` เก็บรหัส Wi-Fi |
| Nano | EEPROM | เริ่มที่ address 0 ใช้รูปแบบเดียวกับ ESP32 |

ก้อนข้อมูลเก็บมาตราส่วน แผนที่แรงเป็นความลึก ช่วง กก. และโปรไฟล์
การเปลี่ยนโปรไฟล์ที่แถว **โปรไฟล์** ในหน้าตั้งค่าจะมีผลทันที
แต่จะอยู่ต่อหลังรีบูตก็ต่อเมื่อสั่ง `cal save` แล้วเท่านั้น

## คืนค่าเริ่มต้น

```
cal reset
cal save
```

`cal reset` คืนค่าในหน่วยความจำชั่วคราวและส่ง `cfg` ใหม่
ถ้าต้องการให้ค่าเริ่มต้นอยู่หลังรีบูต ต้องตามด้วย `cal save`
หลังคืนค่า ให้ตั้งศูนย์และตั้งน้ำหนักใหม่ก่อนใช้งานจริง

## ตรวจว่าปรับเทียบสำเร็จ

- วางของที่รู้น้ำหนัก เช่น ขวดน้ำ 2.0 กก. แล้วดูค่า กก. ในหน้าเว็บ
  ควรใกล้เคียงค่าจริง
- กดช่วงแรกประมาณ 3 ซม. ค่า กก. ควรยังใกล้ศูนย์
- กดต่อไปอีกเล็กน้อย ค่า กก. จึงเริ่มขึ้น
- ส่ง `config` แล้วดู `cfg`
  - `prof` เป็น 1 เมื่อใช้โปรไฟล์เด็ก (ค่าเริ่มต้น) และ 0 เมื่อใช้ผู้ใหญ่
  - `unit` เป็น `mm` เมื่อใช้แผนที่ และเป็น `kg` เมื่อใช้แรงล้วน
  - `gmin`, `dmin` คือช่วงความลึกเป็นมิลลิเมตร
  - `gkg`, `dkg` คือช่วงความลึกเป็นกิโลกรัม
  - `ckg`, `rkg`, `flt` คือ เริ่มกด, คืนตัว และความไว (มีเฉพาะ ESP32)
  - `map` คือจำนวนจุดของแผนที่ ถ้ามากกว่า 1 แปลว่ามีแผนที่แล้ว
- กดหนึ่งครั้งแล้วดูหน้าสรุปว่าความลึกอยู่ในช่วงที่ตั้งไว้
- ถ้าค่าเพี้ยน ให้ `tare` ใหม่ แล้วลองชั่งของที่รู้น้ำหนักอีกครั้ง

## ข้อควรระวัง

- ค่าปรับเทียบผูกกับหนังยางและโครงหุ่นชุดนี้ ไม่สามารถใช้ข้ามหุ่นได้
- หนังยางหย่อนตามเวลา ควรตรวจช่องว่าง 3 ซม. และตั้งศูนย์ก่อนฝึกทุกครั้ง
- อย่าตั้งตัวหยุดให้ลึกขึ้นเพื่อให้ได้เลข 6 ซม. ถ้าโหลดเซลล์เริ่มรับแรงมาก
- ถ้าใช้แผนที่ความลึก ควรมีจุดข้อมูลทั้งช่วงตื้นและช่วงลึก ไม่ควรเก็บแต่จุดเดียว
