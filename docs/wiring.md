# การต่อสาย

เอกสารนี้ใช้ขาจริงจาก `src/esp32/pins.h` และ `src/nano/pins.h`
ต่อสายตอนที่ไม่ได้เสียบไฟ และตรวจขั้วให้ดีก่อนเปิดเครื่อง

> สื่อการเรียนรู้ ไม่ใช่เครื่องมือแพทย์

## หลักที่ต้องจำ

- ESP32 ใช้ไฟเลี้ยง 3.3 V และขา GPIO รับได้ไม่เกิน 3.3 V
- HX711 บน ESP32 ต้องเลี้ยงด้วย **3.3 V** เพราะขา DT จะส่งระดับไฟตาม VCC
  ถ้าเลี้ยง 5 V ขา DT จะเป็น 5 V และอาจทำให้ ESP32 เสียหาย
- HX711 บน Nano เลี้ยง 5 V ได้ เพราะ ATmega328P ทำงานที่ 5 V
- LED ทุกดวงต่อตัวต้านทาน 220–330 โอห์มที่ขาบวก แล้วต่อขาลบลง GND
- บัซเซอร์เป็นแบบ active ขาบวกเข้าขา GPIO ขาลบลง GND
  ขา GPIO จ่าย HIGH แล้วมีเสียง
- สวิตช์ฟอยล์ต่อระหว่างขา GPIO กับ GND ใช้ `INPUT_PULLUP`
  เมื่อมือกด ฟอยล์แตะกัน ขาจะอ่านเป็น LOW
- VL53L0X ใช้ I²C และติดตั้งได้เฉพาะ ESP32 ในเฟิร์มแวร์รุ่นนี้
  บน Nano มีขา A4/A5 แต่ build ปกติไม่พอพื้นที่ flash

## ESP32

| ส่วน | ขาของส่วน | ขาของบอร์ด | หมายเหตุ |
|---|---|---|---|
| HX711 | VCC | 3V3 | ต้อง 3.3 V |
| HX711 | GND | GND | ใช้ GND ร่วมกัน |
| HX711 | DT / DOUT | GPIO16 | ข้อมูลออกจาก HX711 |
| HX711 | SCK / PD_SCK | GPIO17 | นาฬิกา |
| HX711 | E+ | สาย excitation + ของโหลดเซลล์ | มักเป็นสายแดง |
| HX711 | E- | สาย excitation - ของโหลดเซลล์ | มักเป็นสายดำ |
| HX711 | A+ | สาย signal + ของโหลดเซลล์ | มักเป็นสายเขียวหรือขาว |
| HX711 | A- | สาย signal - ของโหลดเซลล์ | มักเป็นสายขาวหรือเขียว |
| บัซเซอร์ active | + | GPIO25 | HIGH = มีเสียง |
| บัซเซอร์ active | - | GND | |
| LED POS | ขาบวกผ่าน R 220–330 Ω | GPIO26 | ตำแหน่งมือ |
| LED GOOD | ขาบวกผ่าน R 220–330 Ω | GPIO27 | ความลึกพอดี |
| LED SHALLOW | ขาบวกผ่าน R 220–330 Ω | GPIO18 | ตื้นไป |
| LED DEEP | ขาบวกผ่าน R 220–330 Ω | GPIO19 | ลึกเกินไปหรือเกินแรง |
| สวิตช์ฟอยล์ | แผ่นที่ 1 | GPIO33 | เปิด `INPUT_PULLUP` |
| สวิตช์ฟอยล์ | แผ่นที่ 2 | GND | |
| VL53L0X | VIN | 3V3 | ดูหมายเหตุไฟเลี้ยงด้านล่าง |
| VL53L0X | GND | GND | |
| VL53L0X | SDA | GPIO21 | |
| VL53L0X | SCL | GPIO22 | |

สีสายของโหลดเซลล์ต่างกันตามผู้ผลิต ให้ดูฉลากบนตัวโหลดเซลล์หรือใบข้อมูล
ถ้าเป็นแบบ 6 สาย ให้ต่อเฉพาะ E+, E-, A+, A- และปล่อย B+, B- ไว้

VL53L0X มีหลายแบบ บอร์ดส่วนใหญ่รับ 3.3–5 V และมีตัวแปลงระดับไฟในตัว
ถ้าใช้บอร์ดที่รับ 5 V ได้ จะเลี้ยง 5 V ก็ได้ แต่ถ้าไม่แน่ใจให้ใช้ 3.3 V
เพราะ ESP32 ไม่ทนไฟ 5 V บนขา GPIO

### รูปการต่อ ESP32

```
                       ESP32
                    ┌─────────┐
   HX711 VCC ───────┤ 3V3     │
   HX711 GND ───────┤ GND     │
   HX711 DT  ──────>│ GPIO16  │
   HX711 SCK <──────┤ GPIO17  │
                    │         │
   บัซเซอร์ + <──────┤ GPIO25  │
   บัซเซอร์ - ──────┤ GND     │
                    │         │
   LED POS   <──R───┤ GPIO26  │
   LED GOOD  <──R───┤ GPIO27  │
   LED SHAL. <──R───┤ GPIO18  │
   LED DEEP  <──R───┤ GPIO19  │
   LED ลบทั้ง 4 ─────┤ GND     │
                    │         │
   ฟอยล์แผ่น 1 ─────┤ GPIO33  │
   ฟอยล์แผ่น 2 ─────┤ GND     │
                    │         │
   VL53L0X SDA ─────┤ GPIO21  │
   VL53L0X SCL ─────┤ GPIO22  │
   VL53L0X VIN ─────┤ 3V3     │
   VL53L0X GND ─────┤ GND     │
                    └─────────┘

   HX711                    โหลดเซลล์ 20 กก.
   E+  ──────────────────── สาย excitation +
   E-  ──────────────────── สาย excitation -
   A+  ──────────────────── สาย signal +
   A-  ──────────────────── สาย signal -
```

## หมายเหตุเรื่อง HX711

HX711 ที่ซื้อมาใช้งานทั่วไปมักต่อขา RATE ไว้กับ GND ทำให้อ่านได้ 10 ครั้ง/วินาที
ที่อัตรากด 110 ครั้ง/นาที การกดหนึ่งครั้งกินเวลาประมาณ 270 มิลลิวินาที
จึงได้เพียง 2–3 ค่า และอาจพลาดยอดกด วิธีแก้คือยกขา RATE ออกจาก GND
แล้วต่อไปที่ DVDD หรือ VCC เพื่อให้อ่านได้ 80 ครั้ง/วินาที
รายละเอียดอยู่ใน [`troubleshooting.md`](troubleshooting.md)

## ตรวจก่อนเปิดไฟ

- ตรวจว่า VCC ของ HX711 บน ESP32 อยู่ที่ 3.3 V จริง
- ตรวจว่า LED มีตัวต้านทานครบทุกดวง
- ตรวจขั้วบัซเซอร์ว่าขาบวกเข้าขา GPIO
- ตรวจว่าฟอยล์สองแผ่นไม่แตะกันตอนที่ยังไม่กด
- ตรวจว่า VL53L0X ไม่ได้อยู่ใต้ฟองน้ำหรือมีอะไรบังลำแสง
- ต่อ GND ของทุกส่วนเข้ากับบอร์ดเดียวกัน
