# การต่อสาย

เอกสารนี้ใช้ขาจริงจาก `src/esp32/pins.h` และ `src/nano/pins.h`
ต่อสายตอนที่ยังไม่เสียบไฟ และเช็กขั้วให้ดีก่อนเปิดเครื่อง

> สื่อการเรียนรู้ ไม่ใช่เครื่องมือแพทย์

## หลักที่ต้องจำ

- ESP32 ใช้ไฟเลี้ยง 3.3 V และขา GPIO รับได้ไม่เกิน 3.3 V
- HX711 บน ESP32 ต้องเลี้ยงด้วย 3.3 V เพราะขา DT จะส่งระดับไฟตาม VCC
  ถ้าเลี้ยง 5 V ขา DT จะเป็น 5 V และอาจทำให้ ESP32 เสียหาย
- HX711 บน Nano เลี้ยง 5 V ได้ เพราะ ATmega328P ทำงานที่ 5 V
- LED ทุกดวงต่อตัวต้านทาน 220–330 โอห์มที่ขาบวก แล้วต่อขาลบลง GND
- บัซเซอร์เป็นแบบ active ขาบวกเข้าขา GPIO ขาลบลง GND
  ขา GPIO จ่าย HIGH แล้วมีเสียง
- ต่อ GND ของทุกส่วนเข้ากับบอร์ดเดียวกัน

## ESP32 รุ่นสุดท้าย

| ส่วน | ขาของส่วน | ขาของบอร์ด | หมายเหตุ |
|---|---|---|---|
| HX711 | VCC | 3V3 | ต้อง 3.3 V |
| HX711 | GND | GND | ใช้ GND ร่วมกัน |
| HX711 | DT / DOUT | GPIO16 | ข้อมูลออกจาก HX711 |
| HX711 | SCK / PD_SCK | GPIO17 | นาฬิกา |
| HX711 | E+ | สาย excitation + ของโหลดเซลล์ | มักเป็นสายแดง |
| HX711 | E- | สาย excitation - ของโหลดเซลล์ | มักเป็นสายดำ |
| HX711 | A+ | สาย signal + ของโหลดเซลล์ | มักเป็นสายเขียวหรือขาว |
| HX711 | A- | สาย signal - ของโหลดเซลล์ | มักเป็นสายขาวหรือเขียว |
| บัซเซอร์ active | + | GPIO25 | HIGH = มีเสียง |
| บัซเซอร์ active | - | GND | |
| LED กำลังกด | ขาบวกผ่าน R 220–330 Ω | GPIO26 | ติดตอนที่กำลังกด |
| LED ลึกพอดี | ขาบวกผ่าน R 220–330 Ω | GPIO27 | ความลึกอยู่ในช่วง |
| LED ตื้นไป | ขาบวกผ่าน R 220–330 Ω | GPIO18 | กดไม่ถึง |
| LED ลึกไป / แรงเกิน | ขาบวกผ่าน R 220–330 Ω | GPIO19 | ลึกเกินหรือเกินแรง |
| LED ลบทั้ง 4 | - | GND | |

สีสายของโหลดเซลล์ต่างกันตามผู้ผลิต ให้ดูฉลากบนตัวโหลดเซลล์หรือใบข้อมูล
ถ้าเป็นแบบ 6 สาย ให้ต่อเฉพาะ E+, E-, A+, A- และปล่อย B+, B- ไว้

### รูปการต่อ ESP32

```
                       ESP32
                    ┌─────────┐
   HX711 VCC ───────┤ 3V3     │
   HX711 GND ───────┤ GND     │
   HX711 DT  ──────>│ GPIO16  │
   HX711 SCK <──────┤ GPIO17  │
                    │         │
   บัซเซอร์ + <──────┤ GPIO25  │
   บัซเซอร์ - ──────┤ GND     │
                    │         │
   LED กำลังกด <──R──┤ GPIO26  │
   LED ลึกพอดี <──R──┤ GPIO27  │
   LED ตื้นไป  <──R──┤ GPIO18  │
   LED ลึกไป   <──R──┤ GPIO19  │
   LED ลบทั้ง 4 ─────┤ GND     │
                    └─────────┘

   HX711                    โหลดเซลล์ 20 กก.
   E+  ──────────────────── สาย excitation +
   E-  ──────────────────── สาย excitation -
   A+  ──────────────────── สาย signal +
   A-  ──────────────────── สาย signal -
```

LED ทั้งสี่ดวงบอกผลคนละอย่าง

- GPIO26 กำลังกด: ติดตอนที่แผ่นกดถูกกด ดับเมื่อปล่อย
- GPIO27 ลึกพอดี: ค่าอยู่ในช่วงผ่าน
- GPIO18 ตื้นไป: ค่ายังไม่ถึงช่วงผ่าน
- GPIO19 ลึกไป / แรงเกิน: ค่าเกินช่วงหรือเกินแรงที่ตั้งไว้

## Arduino Nano (build เก่า)

Nano เป็น build เดิม ยังอ่านสวิตช์มือที่ขา D9 และใช้ไฟ 5 V
ตารางนี้เก็บไว้สำหรับคนที่ยังใช้บอร์ดเดิม

| ส่วน | ขาของส่วน | ขาของบอร์ด | หมายเหตุ |
|---|---|---|---|
| HX711 | VCC | 5V | Nano ใช้ไฟ 5 V |
| HX711 | GND | GND | |
| HX711 | DT / DOUT | D3 | |
| HX711 | SCK / PD_SCK | D2 | |
| HX711 | E+ | สาย excitation + | |
| HX711 | E- | สาย excitation - | |
| HX711 | A+ | สาย signal + | |
| HX711 | A- | สาย signal - | |
| บัซเซอร์ active | + | D8 | HIGH = มีเสียง |
| บัซเซอร์ active | - | GND | |
| LED กำลังกด | ขาบวกผ่าน R 220–330 Ω | D4 | ติดตามตำแหน่งมือใน build เก่า |
| LED ลึกพอดี | ขาบวกผ่าน R 220–330 Ω | D5 | |
| LED ตื้นไป | ขาบวกผ่าน R 220–330 Ω | D6 | |
| LED ลึกไป / แรงเกิน | ขาบวกผ่าน R 220–330 Ω | D7 | |
| สวิตช์มือ | แผ่นที่ 1 | D9 | เปิด `INPUT_PULLUP` |
| สวิตช์มือ | แผ่นที่ 2 | GND | |

```
   HX711 SCK <───────┤ D2        │
                      │           │
   บัซเซอร์ + <───────┤ D8        │
   บัซเซอร์ - ───────┤ GND       │
                      │           │
   LED กำลังกด <──R───┤ D4        │
   LED ลึกพอดี <──R───┤ D5        │
   LED ตื้นไป  <──R───┤ D6        │
   LED ลึกไป   <──R───┤ D7        │
   LED ลบทั้ง 4 ──────┤ GND       │
                      │           │

                      └───────────┘
```

## หมายเหตุเรื่อง HX711

HX711 ที่ซื้อมาใช้งานทั่วไปมักต่อขา RATE ไว้กับ GND ทำให้อ่านได้ 10 ครั้ง/วินาที
ซึ่งพอใช้และไม่ต้องแก้ สำหรับการฝึกทั่วไป

ถ้าอยากให้จับการกดเร็ว ๆ ได้ดีขึ้น ยกขา RATE ออกจาก GND แล้วต่อไปที่ DVDD
หรือ VCC (บน ESP32 ใช้ 3.3 V) จะอ่านได้ 80 ครั้ง/วินาที
รายละเอียดอยู่ใน [`troubleshooting.md`](troubleshooting.md)

## ตรวจก่อนเปิดไฟ

- ตรวจว่า VCC ของ HX711 บน ESP32 อยู่ที่ 3.3 V จริง
- ตรวจว่า LED มีตัวต้านทานครบทุกดวง
- ตรวจขั้วบัซเซอร์ว่าขาบวกเข้าขา GPIO
- ต่อ GND ของทุกส่วนเข้ากับบอร์ดเดียวกัน
- ตรวจว่าไม่มีอะไรกดแผ่นกดตอนเปิดเครื่อง

## หมายเหตุ build เก่า

build เก่าบางรุ่นเคยใช้ VL53L0X ต่อที่ SDA/SCL และใช้สวิตช์ฟอยล์
โค้ดยังอยู่หลัง `USE_VL53L0X` และ `CPR_HAS_FOIL` แต่ build ESP32 รุ่นสุดท้ายปิดทั้งคู่
